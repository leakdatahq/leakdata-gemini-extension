# Security policy

Report a suspected vulnerability privately to `security@leakdata.io`. Do not include real credentials, OAuth tokens, browser cookies, plaintext passwords, complete password hashes, raw breach records, or personal data in a public GitHub issue.

For account and product support, contact `support@leakdata.io`.

## Supported release

Security fixes target the latest released extension version. Until `RELEASE_CHECKLIST.md` is complete and version `1.0.0` is published, this repository is a release candidate and has no supported public release.
